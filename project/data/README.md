# Data

В этой папке хранятся демонстрационные и исследовательские данные проекта.

## Структура

- `audio/` — аудиофайлы AMI встреч.
- `gold/` — gold-аннотации встреч в JSON.
- `sample/` — небольшие образцы для быстрых тестов.

## Правила

- не хранить личные или закрытые данные;
- не добавлять большие файлы без необходимости;
- при расширении датасета фиксировать источник и формат.
