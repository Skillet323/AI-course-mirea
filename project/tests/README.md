# Tests

Минимальный набор тестов для проекта.

## Что стоит проверять

- assignment logic;
- evaluation metrics;
- импорт основных модулей;
- smoke-проверку схем и вспомогательных функций.

## Запуск

```bash
pytest tests
```

## Рекомендуемый минимум

- `test_assignment.py`
- `test_evaluation.py`
- `test_smoke.py` или `test_config.py`
