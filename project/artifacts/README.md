# Artifacts

Папка для результатов экспериментов и итоговых артефактов.

## Что здесь лежит

- `model_comparison.csv` — сводная таблица сравнения моделей.
- `model_comparison.json` — тот же результат в JSON.
- `evaluation_reports/` — отчёты по evaluation run.

## Рекомендация

Сохранять сюда:
- финальные сводки;
- графики;
- выгрузки метрик;
- результаты batch-запусков.
